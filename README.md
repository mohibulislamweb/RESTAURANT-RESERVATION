# TastyBites - Restaurant Reservation App

A full-stack MERN (MongoDB, Express, React, Node.js) web application designed for a modern restaurant, allowing users to explore the menu, learn about the restaurant, and book table reservations seamlessly.

## Features
- **Interactive Home & Menu**: Showcases popular dishes, restaurant services, and details.
- **Table Reservation System**: Simple and fast reservation form with real-time feedback.
- **Responsive UI**: Built with React and customized styling for seamless mobile and desktop experience.
- **RESTful API**: Secure backend built with Node.js and Express connected to MongoDB.

## Tech Stack
- **Frontend**: React.js, React Router, React Scroll, Lucide/React Icons
- **Backend**: Node.js, Express.js
- **Database**: MongoDB (Mongoose)
- **Deployment**: 
  - Frontend: Vercel ([Live Link](https://restaurant-reservation-murex-nine.vercel.app))
  - Backend: Render ([API Link](https://restaurant-backend-tocc.onrender.com))
